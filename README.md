# Vrinda Stores Sales Analytics Dashboard (Excel)

## Project Overview
This Excel dashboard analyzes Vrinda Stores’ 2022 sales data to identify trends in sales, customer demographics, order status, and regional performance.

## Key Insights
- Women customers contribute ~64% of total sales
- Maharashtra generates the highest revenue
- Amazon and Flipkart are top sales channels
- Peak sales observed in Q1 months

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Slicers
- Data Visualization
